# Chordtune Teller

A browser-based guitar chord detector and alternative-voicing explorer, built with native JavaScript, the Web Audio API, and SVG.

The application identifies live guitar chords using spectral analysis and temporal confirmation, then presents alternative fingerings in a fortune teller-inspired interface.
